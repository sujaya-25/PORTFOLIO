## 🚀 Featured Projects

### 1. 👁️ SightX — Real-Time AI Vision Assistant

A real-time AI vision application that uses a webcam and YOLO object detection to identify objects and provide simple scene descriptions.

**Tech Stack:** Python, Streamlit, YOLO, OpenCV, WebRTC

**Key Features:**

* Real-time webcam object detection
* Bounding boxes and object counts
* Simple scene description
* Browser-based text-to-speech output

🔗 **Repository:** https://github.com/sujaya-25/SightX

---

### 2. 💰 RecoverAI — AI Revenue Recovery Dashboard

A Streamlit and Pandas dashboard that analyzes failed payment transactions and identifies recovery opportunities.

**Tech Stack:** Python, Streamlit, Pandas, Data Analysis

**Key Features:**

* Analyzes failed payment transactions
* Estimates recovery potential
* Prioritizes transactions
* Provides data-driven recommendations

---

### 3. 🎓 GuidEx — Intelligent Examination Hall Guidance & Security System

An examination hall guidance and verification system combining **RFID identification and fingerprint verification**.

**Tech Stack:** Python, Tkinter, RFID, R307 Fingerprint Sensor, Arduino, CSV

**Key Features:**

* RFID-based student identification
* Fingerprint-based verification
* Student and exam hall information display
* Seat allocation through a GUI
* CSV/Excel-based student records

🔗 **Repository:** https://github.com/sujaya-25/GUIDEX

---

### 4. 🌧️ Automatic Rain-Sensing Retractable Clothesline

An embedded automation system that detects rainfall and automatically retracts the clothesline to protect clothes.

**Tech Stack:** ATmega328P, Arduino, Embedded C, HL-83 Rain Sensor, Servo Motor

**Key Features:**

* Automatic rain detection
* Motor-based clothesline retraction
* Microcontroller-based control
* Simple outdoor automation

---

### 5. 🔐 Smart Fingerprint Door Lock System

A biometric access control system using a fingerprint sensor and Arduino.

**Tech Stack:** Arduino, R307, Fingerprint Sensor, Relay, Embedded C

**Key Features:**

* Fingerprint-based verification
* Arduino-controlled access
* Relay-based locking mechanism
* Basic biometric security
